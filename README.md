# TETRA by Hecate Robotics
###### 150G UK Antweight / US Fairyweight Full Combat
###### Horizontal Undercutter Spinner

TETRA was the first bot that Hecate Robotics created. Despite its small size, it plays host to a destructive horizontal undercutter. Designed since December 2024, it evolved from a drisk spinner, to a vertical spinner, and finally to an undercutter. Currently, TETRA is being planned out for physical building and hopefully will be competing soon.

TETRA's files are now available to the public so that anyone who is starting out in combat robotics can reference the design and use that to create their own robots. The files are provided in a .f3d format, compatible with Fusion 360.
